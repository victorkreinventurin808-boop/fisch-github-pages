# Fisch — Guia do Pescador

Site estático desenvolvido para o Trabalho Avaliativo 01 de Desenvolvimento Web I.

## Tecnologias

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

O projeto não utiliza JavaScript, frameworks ou temas prontos.

## Estrutura

```text
fisch-github-pages/
├── index.html
├── style.css
├── README.md
└── RELATORIO.md
```

## Publicação

O site deve ser publicado pelo GitHub Pages usando a branch `main` e a pasta `/ (root)` como fonte de publicação.

Depois de ativado, o endereço normalmente segue o formato:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
