# Relatório de Aprendizagem — GitHub Pages

## 1. Tema escolhido

Escolhi desenvolver uma página sobre **Fisch**, um jogo de pesca que conheço e tenho interesse. A proposta foi criar um pequeno guia para iniciantes, apresentando progressão, equipamentos e dicas de pesca.

## 2. Ferramentas utilizadas

- **Visual Studio Code:** para escrever e editar o HTML e o CSS.
- **Navegador:** para testar a página e verificar o layout.
- **Git:** para versionar as alterações.
- **GitHub:** para armazenar o código em um repositório público.
- **GitHub Pages:** para publicar a página na internet.

## 3. Desenvolvimento

Primeiro criei o arquivo `index.html`, que contém a estrutura e o conteúdo da página. Depois criei o arquivo `style.css`, responsável pela aparência, espaçamento, tipografia, cores e adaptação para telas menores.

A estrutura foi organizada em seções: início, progressão, equipamentos, dicas e rodapé.

## 4. Versionamento com Git

Os comandos principais utilizados foram:

```bash
git init
git add .
git commit -m "cria estrutura inicial do site"
git branch -M main
git remote add origin URL_DO_REPOSITORIO
git push -u origin main
```

## 5. Publicação no GitHub Pages

Depois de enviar os arquivos para o repositório público, acessei as configurações do repositório e ativei o GitHub Pages.

Configuração utilizada:

- Source: GitHub Actions ou Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

## 6. Problemas encontrados

Página do Git Hub pages com erro 404
Dei um F5 e atualizando a pagina o site foi publicado

## 7. O que aprendi

Com o trabalho, aprendi a diferença entre criar uma página localmente e publicar essa página na internet. Também pratiquei a organização de arquivos HTML e CSS e entendi a função básica do Git para registrar versões do projeto.

Além disso, aprendi que o GitHub Pages pode transformar um repositório com uma página estática em um site acessível publicamente.

## 8. Conclusão

O resultado foi uma página estática feita com HTML e CSS e publicada pelo GitHub Pages. O processo ajudou a entender, na prática, como um projeto web pode ser desenvolvido, versionado e disponibilizado na internet.
